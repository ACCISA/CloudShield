# WebUI

**WebUI** is a secure, browser-based administrative dashboard that enables organization administrators to manage their **cloud workstations**, **employees**, and **infrastructure configurations**.  
It centralizes IT asset management, security monitoring, and customization settings into one unified platform.

---

## Features

- **Employee Management:** Add, remove, and manage users across departments.  
- **Workstation Configuration:** Assign, customize, and monitor employee workstations.  
- **IT Asset Management (ITAM):** Keep track of hardware, software, and license inventory.  
- **File Storage Configuration:** Manage and secure company file storage systems.  
- **Threat Detection Dashboard:** View real-time alerts and threat intelligence from the automated detection system.  
- **Audit Logging:** Track changes, log admin actions, and maintain compliance.  
- **Role-Based Access Control:** Granular permissions for administrators, analysts, and auditors.  

---

## Project Overview

The **WebUI** is the administrative control center of the company’s secure remote access ecosystem.  
It integrates with backend services responsible for:
- Workstation provisioning  
- VPN and network management  
- Threat detection and alerting  
- Storage and configuration policies  

Administrators use this interface to:
- Manage employee access and system permissions  
- Configure workstation templates  
- Review system health and security status  
- Respond to alerts generated by the threat detection engine
