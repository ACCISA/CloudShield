# DesktopUI

DesktopUI is the main desktop interface for users to securely connect to their company VPN or cloud-based workstations. It provides a simple and unified interface to manage secure network connections and workspace access across multiple environments.

---

## Features

- **VPN Connection Management:**  
  Connect to the company’s VPN with a single click. The app handles authentication, key management, and connection monitoring.

- **Cloud Workstation Access:**  
  Launch and connect to cloud-hosted development or production environments directly from the interface.

- **Secure Authentication:**  
  Supports single sign-on (SSO), multi-factor authentication (MFA), and certificate-based login.

- **Status Dashboard:**  
  View active connections, connection history, and real-time session status.

- **Cross-Platform Support:**  
  Available for Windows, macOS, and Linux.
